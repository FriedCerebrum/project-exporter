ProjectExporter
Описание проекта
ProjectExporter — это инструмент для создания единого файла с полной структурой проекта и кодовой базой. Утилита позволяет быстро и удобно экспортировать весь код из множества файлов в один документ, который можно передать AI-ассистентам (например, Claude) для анализа и помощи с кодом, когда нет возможности загрузить каждый файл по отдельности.
Основные возможности

Полная структура проекта — создание наглядного дерева директорий и файлов
Содержимое всех файлов — экспорт кода с сохранением форматирования
Интеллектуальное определение кодировки — корректная обработка файлов с разными кодировками
Различение бинарных и текстовых файлов — автоматическое определение формата
Гибкие настройки фильтрации — возможность игнорирования ненужных директорий и расширений
Base64-кодирование — создание компактной версии проекта для более удобной передачи

Установка
# Клонировать репозиторий
git clone https://github.com/username/project-exporter.git

# Перейти в директорию проекта
cd project-exporter

# Скрипт не требует дополнительных зависимостей, кроме стандартной библиотеки Python

Использование
Базовое использование:
python export_project.py /путь/к/вашему/проекту

С указанием имени выходного файла:
python export_project.py /путь/к/вашему/проекту путь/к/результату.md

Параметры настройки
Скрипт имеет предустановленные игнорируемые директории и расширения файлов:
Игнорируемые директории по умолчанию:

target
.git
.idea
node_modules
build
dist
ignore
.vscode

Игнорируемые расширения по умолчанию:

Бинарные файлы (.class, .jar, .war, .ear, .zip, и т.д.)
Изображения (.png, .jpg, .jpeg, .gif, .bmp, .ico)
Документы (.pdf)

Для изменения этих настроек вы можете модифицировать код функции export_project_structure.
Принцип работы

Обход директорий: рекурсивно проходит по всем директориям проекта
Генерация структуры: создает дерево файлов и директорий проекта
Чтение содержимого: извлекает содержимое всех текстовых файлов
Определение кодировки: использует несколько методов для правильного определения кодировки файлов
Форматирование выходного файла: создает документ в формате Markdown с четкой структурой
Base64 кодирование: создает сжатую версию всего проекта для облегчения передачи

Преимущества использования

Быстрый обзор проекта — весь код доступен в одном файле
Удобная работа с AI-ассистентами — нет необходимости загружать множество файлов по отдельности
Сохранение контекста — AI-ассистент видит структуру проекта и все файлы одновременно
Поддержка разных кодировок — корректная обработка файлов с различными кодировками

Технические детали
ProjectExporter написан на чистом Python и использует только стандартные библиотеки:

os — для работы с файловой системой
base64 — для кодирования проекта
tempfile — для создания временных файлов
sys — для доступа к аргументам командной строки
codecs — для работы с различными кодировками
